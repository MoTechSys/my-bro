## 3. عقد حزمة T-70 — نُفذت محلياً في2026-09-18

runner/importer/deadline أدناه موجودة ومختبرة (UC-14 §11)؛ لا تعاود إنشاءها. التالي تحكيم المراجعة وتجربة transport/native ثم G5b؛ اختبار عمليات Python الاصطناعية لا يثبت سلوك خادم Ollama الفعلي.

1. **عقد artifact importer قبل كتابة الكود:** تصدير input محدود، سياق analyst وsource_record، رد أصلي وحالة التشغيل، هوية batch ومحاولة مثبتة. تحقق بصمات البايتات وهويات الحالات وcoverage قبل الإسقاط؛ لا قبول offline_context_only كـcompleted. وثّق هل output_sha256 لرد الدفعة أو artifact الحالة؛ لا تفرض اتساقاً إحصائياً على معنى غير محسوم.
2. **مخزن خاص للمحاولات:** intent محفوظ ومزامن قبل الاتصال؛ قفل/منع هوية مكررة؛ حفظ rejected/failed/timeout؛ رفض symlink/overwrite وjournal جزئي. اختبار انقطاع قبل/بعد كل حد دائم، واستعادة لا تعيد inference تلقائياً. لا أسرار في argv أو السجل العام.
3. **حد زمني شامل:** عزل الاستدعاء في عملية قابلة للإلغاء أو آلية مكافئة تُختبر؛ timeout يغطي الاتصال والheaders وقراءة body البطيئة، لا مجرد socket idle. إغلاق/reap للموارد وعدم تراكم workers. لا قتل خدمة Ollama أو SOC نفسها؛ فشل AI يجب ألا يوقف الجمع.
4. **اختبارات اصطناعية أولاً:** source replay، تغيير bytes/provenance، Aref خاطئ، batch مختلط، قطع/بطء الخدمة، حجم زائد، partial writes، labels leakage؛ ثم مراجعة آلية ثانية وإعادة إنتاج ملاحظاتها، ثم native لدى المشغّل.
5. **التقييم الأصلي:** تثبيت corpus/model/prompt/config/rubric؛ predeclare الحالات وcluster؛ يفضل تنبيه واحد لكل batch في أول تجربة. عدم استقلال المحتوى لا يعالج بتغيير اسم batch. جودة MITRE/السرد تُحكم بشرياً، وليست نتيجة schema validation.

## 4. بوابات النواة التي لا يجوز اختصارها

- P1.1: IDs بلا تعارض ثم `wazuh-analysisd -t` وlogtest وتنبيه فعلي؛ XML المحلي وحده غير كافٍ.
- P1.2: قواعد YARA دائمة مثبتة، تجربة reboot، مطابقة FIM/allowlists؛ Windows native مستقل.
- P1.3: Suricata `-T` وHOME_NET/interface ومسار الحركة الحقيقي؛ لا افتراض رؤية شبكة كاملة.
- P1.4: هوية واتصال الوكيلين معاً بدليل حديث؛ Linux السحابي Ubuntu في جرد2026-09-11، لا Kali لمجرد الاسم.
- P1.5: صلاحيات ومجلدات AR وconfig، Windows ACL/build، وحدود TOCTOU موثقة؛ لا chmod شامل أو تعطيل حماية الجهاز تلقائياً.
- P1.6: auditd UID/GID/policy فعلي؛ أنواع الأوامر والسجلات المختبرة محددة.
- P1.7: المصدر والساعة والظهور والاستجابة تقاس مستقلة؛ تمثيل milliseconds لا يثبت accuracy؛ null ليس صفراً.
- P1.8: صور المختبر الحالية فقط كأدلة نتائج. الصور الرسمية والتوليد والاختبارات الاصطناعية ليست نتائج الفريق.
