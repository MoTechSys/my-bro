## ADR-014 — AI Agent داخل النطاق (قرار المستخدم 2026-09-09)

**القرار:** بناء **AI Agent للتحليل الأمني** كمكوّن أساسي (لا Future Work). يُلغي جزئياً ADR-010 وقرار docs/05 §5 "AI = WON'T".
**المحرّك:** المستخدم صرّح: "قرار واعٍ — AI agent ضروري نبنيه — أذكى موديلات".
**التصميم (3 مستويات):**
- **L1 محلّل:** يقرأ تنبيهات L≥7 من `alerts.json` ويشرحها (السبب، الخطورة، MITRE، الإجراء المقترح) بالعربية/الإنجليزية.
- **L2 مُرابِط:** يجمع تنبيهات متفرقة في سلسلة هجمة واحدة (attack story) — قدرة لا يوفّرها Wazuh أصلاً.
- **L3 مُستجيب مُقيَّد:** يقترح استجابة فقط؛ **لا سلطة تنفيذ** — human-in-the-loop إلزامي.
**القيود:** RAG على (MITRE ATT&CK + قواعدنا 100050–108001 + جرد المعمل) لمنع الهلوسة؛ تنقيح البيانات الحساسة قبل أي API خارجي (IPs داخلية → placeholders)؛ model-agnostic (أي API + خيار Ollama محلي بلا إنترنت).
**القياس (C4):** دقة التصنيف ودقة MITRE mapping مقابل 30 تنبيهاً مُعلَّماً يدوياً؛ زمن التحليل؛ معدل الهلوسة (ادعاءات غير مسندة). Wilson CI كالمعتاد.
**المرجع الأدبي:** Ismail et al. 2025 (Sensors 25(3):870) — Wazuh + RAG LLM؛ إضافتنا: الترابط L2 + القياس المنهجي + الخيار المحلي.
**الأثر:** T-70 جديدة؛ G5 تصير إلزامية؛ ch4 قسم جديد؛ ch5 جدول دقة؛ docs/05 §5 يُعدَّل (AI: WON'T → MUST كمساعد تحليل، لا كمحرك كشف). العنوان لا يتغيّر.
**حالة D5:** محسوم = نعم.
