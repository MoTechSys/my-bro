# UC-14 — المحلل الأمني بالذكاء الاصطناعي (T-70 / ADR-014)

**الحالة:** ✅ مُنفَّذ ومُثبت حياً 2026-09-28. التفاصيل التقنية: `ai_agent/README.md`.

## المستويات
| المستوى | الأمر | الوظيفة | الضمانة |
|---|---|---|---|
| L1 شرح | `python3 ai_agent/soc_ai.py explain --rule 100404` | شرح تنبيه بالعربية: الملخص، الخطورة، MITRE، الخطوات التالية | سياق RAG فقط؛ كل ادعاء يُسنَد بـ`rule:`/`mitre:`؛ معرّف مخترع → رفض → وضع حتمي |
| L2 ترابط | `soc_ai.py correlate [--narrate]` | تجميع التنبيهات في حوادث (IP/ملف/MAC + نافذة 15 د)، سلسلة ATT&CK، درجة خطورة | استبعاد الضجيج (SCA/rootcheck/pam/sudo)؛ ضم نتائج AR لحادثتها |
| L3 اقتراح | `soc_ai.py suggest INC-001` ثم `respond INC-001 block_ip --agent 001 --approver NAME --approve HASH` | اقتراح إجراءات من **قائمة ثابتة** وتنفيذها عبر Wazuh API بعد موافقة بشرية | النموذج يرتّب فقط (لا يضيف)؛ hash الموافقة؛ IPs/حسابات محمية؛ سجل تدقيق JSONL |
| تقرير | `soc_ai.py report --out report.md` | تقرير حوادث يومي | — |

الإجراءات المسموحة فقط: `block_ip` (firewall-drop مؤقت)، `disable_account`، `quarantine_file` (فقط عبر AR الآلي على 87105)، `notify`، `monitor`.

## النموذج
أي خادم OpenAI-compatible: `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `SOC_AI_MODEL` (افتراضي gpt-5-mini). محلياً بلا إنترنت: Ollama `http://127.0.0.1:11434/v1` + `SOC_AI_MODEL=llama3.1`. `SOC_AI_OFFLINE=1` = وضع حتمي بلا نموذج (العرض لا يعتمد على الإنترنت).

## قاعدة المعرفة (RAG، BM25)
قواعدنا + معاني قواعد Wazuh 4.14.7 المدمجة المستخدمة (منسوخة من الحزمة) + **MITRE ATT&CK v19.2** (مستخرج من STIX الرسمي؛ T1562.001/.004 الملغاة مُعلَّمة → T1685/T1686) + runbooks. المصدر: `ai_agent/data/SOURCES.md`.

## الدليل الحي
- L1 على 100404 بـgpt-5-mini: جواب عربي، استشهادات `rule:100404/100402/100401`، `mitre:T1078/T1110`، اجتاز الحارس (~30 ث).
- L2 على alerts.json الحي: حادثة الراوتر = 100401→100402→100404→100411 بسلسلة initial-access → credential-access → discovery، خطورة 100؛ حادثة SSH ضُمّ إليها 651 (AR نُفِّذ → لا اقتراح حظر مكرر).
- L3: اقتراح `block_ip` → موافقة بـhash → `PUT /active-response` → iptables DROP على الوكيل kali1 (001) + 651 + سجل تدقيق. بدون `--approve` يرفض التنفيذ.

## أخطاء وُجدت وأُصلحت أثناء البناء
ISSUE-067 (الأمر عبر API يحتاج `!firewall-drop`)، ISSUE-068 (اقتراح أخذ IP من تنبيه غير مرتبط — خطر)، و`error:0` مع 0 عناصر ليس نجاحاً.
